# Ember & Spice

A modern restaurant marketing website built with Next.js, featuring an elegant visual identity, responsive layouts, and refined animations.

Ember & Spice is a fictional restaurant website developed as a portfolio project to demonstrate frontend development, responsive design, component architecture, and modern web technologies.

**[🌐 Live Demo](https://ember-spice-tau.vercel.app/)**

---

## ✨ Features

- Premium restaurant-inspired visual design
- Responsive layouts for desktop, tablet, and mobile
- Animated interactions and transitions
- Reusable React components
- Restaurant menu and gallery sections
- Configurable restaurant information and navigation
- SEO and Open Graph metadata configuration
- Structured data (JSON-LD) configuration
- Accessible color choices and interface elements

---

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** JavaScript
- **Styling:** Tailwind CSS 3
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm

### 1. Clone the repository

```bash
git clone https://github.com/arzenjs/ember-spice/
```

### 2. Navigate to the project directory

```bash
cd ember-spice
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🧪 Development Commands

Run the linter:

```bash
npm run lint
```

Create a production build:

```bash
npm run build
```

Start the production server:


## 📁 Project Structure

Key configuration and content files:

| Path | Purpose |
|---|---|
| `src/config/restaurant.js` | Restaurant details, contact information, hours, and social links |
| `src/config/navigation.js` | Navigation configuration |
| `src/data/menu.js` | Menu content |
| `src/data/gallery.js` | Gallery image paths and alternative text |
| `src/app/layout.js` | Application layout and structured data configuration |

## 🎨 Design & Accessibility

The visual system combines dark backgrounds, ivory text, and copper-inspired accents to create a refined restaurant aesthetic.

Design considerations include:

- Responsive layouts
- Consistent color usage
- Readable text and interface contrast
- Clear navigation patterns
- Reduced visual obstruction on mobile devices
- Reusable styling conventions

Copper accents are reserved primarily for borders, icons, and larger text where contrast is limited. Lighter copper tones and ivory-on-terracotta combinations provide stronger contrast where needed.

## ⚙️ Configuration

Restaurant details and content are organized into dedicated configuration and data files.

Before adapting this project for a real restaurant, update:

- Restaurant name and contact details
- Address and opening hours
- Menu items and prices
- Restaurant photography
- Social media links
- Footer text and demo labels
- SEO metadata and structured data

**Important:** Ember & Spice is a fictional restaurant concept. Its restaurant details, menu, and associated content are demonstration data and must be replaced before any real-business launch.
